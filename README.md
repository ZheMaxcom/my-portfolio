# Моя візитка

Односторінковий сайт-візитка студента курсу Vibe Coding в IT STEP. На сторінці — ім’я, короткий опис, навички та контакти.

## Технології

- HTML
- CSS
- Cursor AI Agent
- Git

## Як запустити

Відкрийте файл `index.html` у браузері.

## Нова функція: перемикач теми

У правому верхньому куті сторінки є кнопка з іконкою 🌙 або ☀️. Натискання перемикає світлу й темну тему, а обраний варіант зберігається в браузері й відновлюється після оновлення сторінки. Секретні ключі зберігаються у файлі `.env`, який не потрапляє в Git завдяки `.gitignore`.


## Нова функція (ДЗ 6)

Кнопка «Детальніше про мене» показує та ховає додатковий текст про автора. Зроблена на звичайному HTML, CSS і JavaScript без бібліотек, працює у світлій і темній темі та на телефоні.
